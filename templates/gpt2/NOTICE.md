# Where these files come from

The 25 `gpt2model_gpt2_pbf16_b*_s*_modeprefill.json` files in this directory are **traced workload
files from the EnergAIzer (ISPASS'26) artifact**, copied unmodified. They are not generated by this
repository — they are the ground truth it is validated against.

Each one is a flat JSON list of 242 kernels in execution order, captured by running GPT-2 on a real
GPU at one fixed `(batch, seq_len)` in prefill mode.

**Three are anchors**, used to learn the scaling law:

| File | Role |
|---|---|
| `..._b8_s128_...` | base |
| `..._b16_s128_...` | batch doubled, seqlen held |
| `..._b8_s512_...` | seqlen ×4, batch held |

**The other 22 are test targets.** `tests/test_scaling.py` asserts that shapes derived from the three
anchors equal these files exactly, field for field.
